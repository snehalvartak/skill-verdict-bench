Does the validation threshold transfer?

Each threshold was chosen to give 5% false positives on validation. This is the rate it produced on the test sources, with 95% intervals. It follows the test-set switch and is fixed by the pre-registration.

How to read it. If the interval around a dot excludes the 5% line, the threshold chosen on validation did not transfer to the test sources.

How we tested it: five experiments

Each experiment exists because the previous one left a question open.

001

Do per-risk questions beat one generic question?

200 skills, random split

0.80 AUC for the five questions against 0.63 for the generic one

002

Is it the content, the max of five, or batching?

Same 200 skills

AST10 content +0.12 over generic paraphrases; max-of-five +0.045; batching no change

003

Do those hold when the threshold is chosen on separate data?

200 train · 200 val · 200 test

Logistic regression +0.057 over the max; AST04 alone +0.076 over the max

004

Do they hold on sources never seen in training?

1,384 source-disjoint · 1,947 structurally disjoint

Logreg minus generic +0.139 [0.105, 0.172] and +0.129 [0.105, 0.152]

005

Does 004 reproduce, and is five separate calls better than the same five questions in one?

Same test skills as 004

Scores identical to 004 (Spearman 1.000, largest difference 0). Five calls: AUROC 0.672; one call: 0.656

Case study: one source decides the headline

SkillHarm supplies most of the malicious skills in the source-disjoint test set, and no detector that reads only SKILL.md can see why they are harmful.

SkillHarm. Most of its malicious skills score low on all five questions. A reading of 20 sampled misses found 18 where SKILL.md only tells the agent to complete a mandatory preflight or setup step in another file that is not in the dataset, so there is no payload text for the questions to see. SkillScreen also reads SKILL.md only, so its high SkillHarm recall is not from reading those files; it may come from learning that phrasing or the source's style, which this data cannot separate from detecting harm. The sample was chosen by score, and the benchmark label, not the text, says these skills are harmful.

Method and reproduction

Everything needed to check or repeat these numbers.

Limits. One seed per sample; the hosted model has no pinned version, so a silent update would not be flagged (experiment 005 reproduced 004 exactly, which is the only check); only SKILL.md text is scored; the train and validation samples are small; comparisons with published models are descriptive because the models differ. The without-SkillHarm check was run after seeing the results.
